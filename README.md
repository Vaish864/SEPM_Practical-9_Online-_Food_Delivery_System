# SEPM_Practical-9_Online-_Food_Delivery_System
Software Engineering project documentation for an Online Food Delivery System, including the SRS, UML diagrams, project schedule, and test cases.
# Objectives:
Simplify online food ordering and payment.

Manage restaurant menus and customer orders.

Support delivery tracking and order status updates.

Provide administrative management.

# Repository Contents
Software Requirements Specification (SRS)

UML diagrams: Use Case, Activity, Class, Sequence, State Machine, Deployment, and Component

Project schedule and Gantt chart

System test cases

# Proposed Technologies
Web and mobile applications

MySQL / PostgreSQL

REST APIs and HTTPS
